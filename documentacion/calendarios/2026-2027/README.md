Documentos originales facilitados por el centro para contrastar la programación del MP0485.

- `Calendari 2627 FIOC SAGRERA.xlsx`: calendario académico interno (original sin modificar).

## Advertencia sobre el Excel

La hoja `2627` está rotulada como curso 2026-2027, pero algunas celdas de fecha conservan años internos de plantillas anteriores. El formato visual muestra principalmente día y mes, por lo que el desfase puede pasar inadvertido. Debe emplearse como fuente documental provisional y no para cálculos automáticos de fechas sin una revisión previa.

Estos documentos contienen planificación interna del centro y se conservan en este repositorio privado.
