# MP0485 Programación

Repositorio privado de trabajo para la actualización progresiva del módulo **MP0485 Programación** y su incorporación al nuevo Moodle de Monlau.

## Organización

- `presentaciones/AEA1/`: presentaciones PPTX editables ya generadas y validadas.
- `moodle/plantilla-tecnica/`: paquete piloto que se conserva solo como patrón técnico compatible con Moodle.
- `moodle/origen/`: copia del Moodle 1DAM–MP0485 25-26, fuente exclusiva para revisar actividades.
- `documentacion/`: criterios pedagógicos y referencia técnica para futuras actualizaciones.

## Criterios esenciales

- Las presentaciones PPTX sirven también como apuntes del alumnado.
- La copia Moodle 1DAM–MP0485 25-26 es la fuente de actividades: visibles = utilizadas en 25-26; ocultas = banco histórico.
- `MP0485-26-27-PILOT-AEA1-v4.mbz` se usa exclusivamente como plantilla técnica. Su contenido pedagógico no se considera válido.
- Cada futuro paquete Moodle será incremental: contendrá solo la AEA nueva y sus dependencias, sin datos del alumnado.
